# Renight UI 분석 (2026-10-10, 미구독 상태 스크린샷 2장)

## 구조
- 하단 플로팅 탭바 4개: 수면 / 수면 부채 / 수면연구소(콘텐츠) / 마이페이지.

## 화면별
1. 홈(수면)
   - 헤더: 사용자 이름, 수면 부채 배터리 아이콘 + "??시간 ??분", 별 포인트(게이미피케이션)
   - 큰 질문: "지금 주무시나요? 기상 시간을 선택하세요."
   - 휠 피커(시 : 분 오전/오후), 아래 "7시간 35분 동안 잘 수 있어요."
   - 파란 pill CTA "수면 시작하기" -> 소리 재생 시작(추정)
   - 즉, "기상 시간 설정 + 잠들기 시작"이 한 번의 행동
2. 수면 부채(유료, 미리보기)
   - 기간 "9월 27일 - 10월 10일"(2주 창), 큰 숫자 + "위험" 배지, "어제보다 1시간 12분 ↓"
   - 배터리 + 캐릭터 일러스트
   - "권장 취침 시간" 카드: 최근 기상 패턴 기반, "오늘 밤 11:00PM에 잠들면 부채가 더 빨리 회복"
   - 블러 + 구독하기 CTA(파랑)

## 시각 스타일
- 다크, 검정 배경, 단일 강조색 파랑(#4A7BEF 계열). 알라미보다 단순하고 조용함.

## Slipper에 가져올 것
- 홈 = 기상 시간 휠 + "N시간 M분 잘 수 있어요" + 수면 시작 버튼 (한 번에 알람 예약 + 비트 시작 + 취침 기록)
- 수면 부채 (센서 없이 취침/기상 시각만으로 계산 가능) + 권장 취침 시간

## 주의
- Renight도 이미 "기상 시간 설정 -> 수면 시작" 통합 흐름을 가짐. 우리 차별점은 미션 강제 기상 + 기상 데이터(소요시간, 컨디션)로 다음 밤을 조정하는 루프.
