# Renight 내부 동작 분석 (2026-10-19, Android 4.4.0 build 693)

대상: `com.munice.miraclenight_android` (내부 이름 Nightly). 연결된 안드로이드 폰에서 APK를 꺼내 jadx·dexdump로 정적 분석. 앱을 실행해 보지는 않았으므로 "코드에 이렇게 되어 있다"까지만 확실하고, 실제 기기에서 어떻게 체감되는지는 모름.
코드·소리·그림은 가져오지 않는다. 원리만 참고.

## 1. 코골이 감지 (가장 참고할 만함)

관찰한 것:
- 마이크는 소리가 꺼지고 "수면 단계"에 들어간 뒤에 연다 (`수면 단계 진입 — 마이크 연다`). Slipper SPEC 8장과 같은 방향.
- 16kHz 모노, 약 1초(15,600샘플) 단위로 분석.
- 소리 크기(RMS)가 0.001보다 작으면 모델을 돌리지 않음 → 조용한 밤에 배터리 절약.
- 작은 소리는 증폭(최대 8배)해서 모델에 넣음.
- 모델: 구글 공개 모델 YAMNet + 자체 판정층(가중치 1024개 + 1개 = 로지스틱 회귀, `snoring_head_weights.bin` 4,100바이트).
- 판정 방식 "hybrid": 자체 판정 점수 ≥ 0.5 **그리고** YAMNet 기본 "Snoring" 점수가 최근 몇 초 안에 ≥ 0.15 일 때만 코골이. 기본 분류기 하나만 믿지 않고 두 신호가 같이 맞아야 인정.
- 상태 흐름: 대기 → 후보(연속 N번 맞아야 시작) → 코골이 중 → 쉬는 중 → **90초** 동안 다시 안 나오면 한 건으로 마감.
- 밤새 소리를 AAC 24kbps 조각 파일로 저장해 두고, 아침에 각 조각을 주기성·신호 대 잡음비·두드러짐으로 점수 매겨 대표 클립만 고름(시간대별로 골고루). 코골이 세기 타임라인도 만듦.
- 휴대폰이 뜨거우면(thermal) 분석을 건너뜀. 밤사이 배터리 소모율(시간당 %)과 충전 여부를 기록.
- 처음 코골이가 잡히면 한 번 안내를 띄움(`ONCE_SNORING_FIRST_DETECTED_SHOWN`).
- 클립마다 사용자 피드백(맞음/아님)과 "보관" 기능이 있음.
- 녹음 보관 30일, **클립을 서버(Firebase)에 올림** (최대 5개/밤). Slipper는 서버 전송 금지라 이 부분은 우리 강점.

## 2. 알람 신뢰성

관찰한 것:
- `setAlarmClock` 사용. 정확한 알람 권한이 없으면 `setAndAllowWhileIdle`로 대신 예약.
- 울리는 중 같은 알람이 또 오면 무시(중복 방지). 알람이 꺼진 상태면 소리 없이 수면만 종료 처리.
- **앱이 밤사이 업데이트되면**(`MY_PACKAGE_REPLACED`) 예약 시각을 다시 읽어 알람을 재예약하고, 알람 시각이 이미 지났으면 바로 울리고, 아니면 수면 소리를 다시 틈. "수면 중 앱 업데이트됨" 표시도 남김.
- 앱이 강제로 죽었다 살아나면 "None → Alarm"으로 상태 복구.
- 알람 소리 크기는 시스템 알람 음량을 사용자가 정한 값(기본 50%)으로 맞춤.

## 3. 소리 재생

- 모노럴 비트 기본값: 바탕 130Hz, 차이 1Hz.
- 이어폰을 꽂으면 미디어 음량을 4칸 낮춤(2~7칸 사이로 제한). 수면 시작 때 미디어 음량을 정해 둔 값(기본 6/15)으로 맞춤.
- 이어폰일 때 "들리지 않는 모드": 바탕 주파수를 18,000~20,000Hz로 올림. **특허(US 12,725,590) 주변 영역이고 효과 근거도 불분명 → 따라 하지 않음.**

## 4. 수면 부채

- 계산은 **서버**에서 함(`v2/sleep-debt`, `v2/sleep-debt/schedule/recommendation`). 앱에는 공식이 없음.
- 주고받는 값: 수면 부채, 범위, 어제 대비 차이, 권장 수면 시각, 하루 뒤 예상 부채, 최근 기간 수면 기록, 평일/주말 따로 권장 취침·기상 시각.
- 수면 기록에는 시작·끝 시각과 **시간대(timezone)·오프셋**, 사용자가 직접 끝냈는지, 추정 기록인지(`isEsm`, `estimate`), 헬스 커넥트 출처가 들어감.

## 5. Slipper와 비교한 허술한 점

| # | 항목 | 지금 SPEC | Renight | 제안 |
|---|---|---|---|---|
| 1 | 코골이 판정 기준 | "분류기가 코골이로 판단하면" (기준값 없음) | 두 신호 동시 + 연속 N번 | 기준값을 `thresholds.ts`에: 확신도 기준, 연속 몇 초, 마감 간격 |
| 2 | 조용할 때 배터리 | 없음 | 조용하면 분석 안 함 | 소리 크기가 일정 이하면 분류기를 쉬게 |
| 3 | 한 건 마감 간격 | 60초 | 90초 | 60초 유지, 실제 테스트 후 조정(값만 thresholds에) |
| 4 | 밤사이 앱이 꺼짐 | 정의 없음 | 업데이트·강제 종료 복구 | 수면 상태를 저장해 두고, 다시 열면 이어서 녹음 + 리포트에 "중간에 끊겼어요" |
| 5 | 수면 중간에 "종료" | 기록에 끝 시각 없음 → 잔 시간이 알람까지로 계산됨 | 끝낸 시각·사용자가 끝냈는지 저장 | `NightRecord.sleepEnd` 추가 |
| 6 | 시간대 | 시각 문자열만 | 시간대·오프셋 저장 | 기록에 시간대 오프셋 저장 (여행·서머타임) |
| 7 | 폰 발열 | 없음 | 뜨거우면 분석 건너뜀 | iOS 발열 상태가 심각이면 분석 쉬기 |
| 8 | 녹음 보관 | 7일 뒤 모두 삭제 | 클립별 보관·피드백 | (화면 추가 필요 → 사용자 결정) |
| 9 | 수면 부채·권장 취침 | 없음 | 핵심 유료 기능 | (화면 추가 필요 → 사용자 결정) |

## 6. 화면·기능 비교 (한국어 문구 4,541개를 화면별로 묶어 확인)

탭: 수면 / 수면 부채 / 수면 기록(캘린더) / 수면연구소(글) / 마이페이지. 게임(캐릭터·모험·맵·상점·별·레벨), 챌린지, 선물, 시즌 이벤트, 상담 채팅이 큰 비중.

### Renight에만 있는 기능
- 수면 시작 전: 배터리 부족 경고("자는 동안 폰이 꺼지면 알람이 울리지 않을 수 있어요"), 이어폰 연결 시 모드 전환 안내, 마이크로 주변 소음을 재서 볼륨 추천, 오늘 상태 고르기(기분·몸 상태·취침 전 활동·상황), 1분 호흡, 명상, 낮잠 모드
- 수면 중: 잠금 화면 Live Activity("수면 종료 시간"), 수면 중 다른 화면 이동 막기, 화면 녹화 차단
- 알람: 미루기(1~30분), 밀어서 일어나기, 알람 화면 꾸미기(사진·영상), 알람 30분 전 "알파파 유도"(의학적 주장, 따라 하지 않음), iPhone 기본 알람과 같은 시각이면 안 울릴 수 있다는 안내
- 아침: 수면 평가 5단계 + 수면 노트, 결과 문구(푹 잤어요 등), 첫 코골이 감지 안내
- 기록: 캘린더 일간·주간, 기록 추가·삭제, 취침·기상 시각 24시간 안에 수정, 앱을 안 쓴 날은 폰 움직임·걸음 수·수면 일정으로 추정, Apple 건강·삼성 헬스 연동(워치 수면 단계), 잠드는 데 걸린 시간, 알람 후 더 잔 시간, 미루기 횟수, 상태 태그에 따른 조언 문구, 주간 리포트(주 4회 이상)
- 코골이: 총 코골이 시간, 세기 타임라인, 클립 최대 5개, "이 소리는 코골이가 맞나요?" 피드백, "코를 곤 것 같아요"(놓친 것 신고), 감지 꺼짐·감지 없음·분석 중·만료 상태 문구, 이어폰·블루투스 기기를 쓰면 감지가 안 될 수 있다는 안내
- 수면 부채: 최근 14일, 평일·주말 따로 수면 일정, 일일 수면 필요량, 내일 예상 부채, 권장 취침 시각, 낮잠도 반영
- 설정: 취침 시간 알림, 수면 주기(90분 단위 기상 추천), 12/24시간, 교대 근무, 햅틱

### 참고: 개인정보 문구와 코드가 다름
- 화면 문구: "코골이 클립은 사용자 기기에만 저장되며, 다른 곳에 백업되지 않아요."
- 코드: 클립과 session.json을 저장소로 올리는 작업(`SnoringUploadWorker`, 최대 5번 재시도)이 있음. 설정에 "리서치 참여하기"가 있어 동의한 사람만 올릴 수도 있음. 실제로 올리는지는 실행해 보지 않아 모름.

### Slipper SPEC에서 찾은 빈틈
- 6.17 리포트 예시 "주말 목표 8시간 30분"과 5장 "요일 구분 없음"이 서로 맞지 않음.
- 앱 잠금 없이 출시할 경우, 잠그는 시각 알림이 앱 잠금에 묶여 있어 취침 알림이 하나도 없음.
- "밤사이 소리" 카드의 빈 상태가 없음: 녹음 꺼짐 / 아침까지 소리를 틀어 녹음 안 함 / 감지 없음 / 중간에 끊김.
- 블루투스 이어폰이 연결된 채로 녹음하면 이어폰 마이크로 바뀌거나 녹음이 안 될 수 있음. 폰 마이크를 쓰도록 정해야 함.
- 수면 시작 때 배터리 확인이 없음.
