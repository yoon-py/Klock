# Alarmy UI 분석 (2026-10-10, iOS 스크린샷 11장)

## 구조
- 하단 플로팅 pill 탭바 5개: 알람 / 수면 / 아침 / 리포트 / 설정. 선택 탭은 진한 캡슐 배경.
- 알람과 수면이 별도 탭으로 분리됨 (서로 연결이 약함).
- 광고 배너(탭바 아래), 구독 할인 배너(홈 상단) 상시 노출.

## 화면별
1. 홈(알람)
   - 상단: 구독 배너, NEW 기능 홍보 카드
   - 헤드라인: "9시간 24분 후에 울려요 >" (다음 알람까지 남은 시간)
   - 알람 카드: 요일 행, 큰 숫자 시간(오전/오후 작게 앞에), 토글(시안), 미션 아이콘, 라벨(이모지 + "일찍 일어나기"), 케밥 메뉴
   - 우하단 빨간 FAB(+)
2. 미션 선택(모달 시트)
   - 카테고리: 인기 / 정신부터 깨우는 / 몸부터 깨우는
   - 카테고리별 아이콘 타일 색(빨강, 청록, 보라), 배지 AI/NEW/BEST/HOT, PRO 잠금
3. 알람 편집("기상 알람")
   - 카드 섹션: 알람 소리(미리듣기, 볼륨, 진동 체크), 부드럽게 깨우기(30초), 시간/날씨 읽어주기(샘플 칩), 잠금 기능(프리미엄)
   - 커스텀 설정: 미루기(5분, 3회), 알람 배경화면
   - 하단 고정 빨간 "저장" CTA
4. 알람 배경화면: 밈 영상/이미지 캐러셀, 카테고리 칩, 내 사진 업로드
5. 수면 탭: 히어로 카드("나도 모르는 내 잠버릇은 뭘까?" + 샘플 파형), 흰색 "수면 측정하기" 버튼, 내 수면 리포트 링크
6. 권한 사전 안내: 설정 토글 일러스트 + "설정으로 이동" (시스템 팝업 전에 이유 설명)
7. 수면 시작 가이드: 남색 그라데이션 + 별, 일러스트, "휴대폰을 베개 옆에", 충전 권장
8. 수면 측정 중: 큰 시계(00:35), "9시간 24분 후에 알람이 울려요", 보라 파형, 코골이 탐색/주변 소음 dB, "종료", 하단 미니 플레이어(수면 사운드 선택)
9. 리포트: 주간 이동(< 이번 주 >), 칩 탭 기상/수면/습관
   - 기상 리포트: 평균 기상 시각, 평균 기상 소요시간(알람 -> 미션 완료), 요일별 점/막대 + 평균선(주황)
   - 수면 리포트: 평균 수면시간, 잠들기까지 걸린 시간, 수면 단계 범례(깊은 잠/렘/얕은 잠/깸), 빈 상태 + CTA

## 시각 스타일
- 다크 전용. 배경 거의 검정, 카드 #1C1C1E 계열, 큰 radius(~24).
- 강조색 역할 분리: 빨강 = 알람 행동(FAB, 저장), 시안 = 토글, 흰 pill 버튼 = 밤/측정 CTA.
- 시간대 톤: 밤 화면은 남색/보라 + 별, 기상 리포트는 따뜻한 갈색/주황 그라데이션.
- 숫자는 크고 가는 웨이트, 한글 제목은 굵게.

## Slipper에 가져올 것
- 홈 헤드라인 "N시간 M분 후에 울려요"
- 밤 세션 화면 = 큰 시계 + 알람 카운트다운 + 사운드 미니 플레이어 (우리 핵심 화면, 비트 재생기로 대체)
- 기상 소요시간 지표 (= 데이터 루프의 잠깸 지표)
- 시간대별 톤(밤 남색/보라, 아침 주황), 하단 고정 CTA, 권한 사전 안내, 리포트 주간 이동 + 평균선 차트

## 뺄 것 / 다르게 할 것
- 광고, 구독 배너, 미션 카탈로그(구구단 하나 -> 문제 수만 설정), TTS 읽어주기, 밈 배경화면, 마이크 코골이 측정(MVP 제외)
- AlarmKit 알람은 시스템 UI로 울려서 커스텀 배경화면 불가. 미션 화면은 "미션 하기" 탭 후 앱에서.
- 미루기는 stopIntent 재예약 루프와 충돌 -> MVP에선 없음.
- 알람/수면 분리 탭 대신 하나의 흐름: 밤 세션 시작이 곧 내일 알람 확인.
