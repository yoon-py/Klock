# 경쟁 수면 앱 실제 화면 분석

- 조사일: 2026-10-22
- 기기: 갤럭시 A34(SM-A346N), 안드로이드. 아이폰판은 모양이 조금 다를 수 있어요.
- 방법: 앱마다 데이터를 지워 처음 설치한 상태로 만들고, 새 사용자처럼 화면을 하나씩 눌러 가며 스크린샷을 찍었어요. 화면의 글자와 버튼 목록도 함께 읽었어요. 움직이는 화면은 영상으로 녹화하고 프레임을 뽑아 확인했어요.
- 파일: 이 폴더의 `sleepcycle/`, `sleepmonitor/`, `sleepsounds/`, `renight/`. `*.mp4`는 녹화 영상, `*-frames.png`는 영상에서 뽑은 8장짜리 연속 장면이에요. 캡처 파일은 약 200MB라 git에는 올리지 않아요(.gitignore).
- 지킨 규칙: 결제, 무료 체험 시작, 로그인, 회원가입은 하지 않았어요.

**한계**: Sleep Cycle과 Renight는 온보딩이 끝나면 회원가입(구글·이메일·카카오)을 해야만 넘어가요. 건너뛰기가 없어서 두 앱은 소개 화면까지만 봤어요. Sleep Monitor는 가입 없이 모든 탭을 볼 수 있어서 가장 자세히 봤어요.

## 1. Sleep Cycle

**전체 인상**: 짙은 남청색 바탕에 청록 물결 그래프, 버튼만 주황이에요. 단순한 선과 도형으로 만든 애니메이션 스토리로 기능을 설명해요. 사진은 없고, 그림은 모두 단색 벡터예요.

## 5. Sleep Cycle은 결제 안 하면 무엇을 못 쓰나요?

**확인한 것**: 결제보다 회원가입이 먼저 막아요. 가입하지 않으면 소개 애니메이션과 기상 시간 설정 말고는 아무것도 볼 수 없어요.

**확인 못 한 것(추측)**: 가입 후 무료 범위는 보지 못했어요. 앞선 코드 분석과 일반적으로 알려진 바로는, 무료로 기본 측정과 스마트 알람은 되고 코골이·장기 통계·프로그램·소리 대부분은 유료일 가능성이 커요. 검증한 내용은 아니에요.

**비교로 확인한 것**: 같은 방식의 Sleep Monitor는 무료가 기록·분석·리포트 일부뿐이고, 사운드·코골이·잠꼬대·추이·메모·백업·주변 소음·스마트 알람·무호흡이 유료예요([17-paywall-scrolled.png](sleepmonitor/17-paywall-scrolled.png)).

## 6. 공통 패턴

- **온보딩**: 로고 애니메이션 → 한 화면에 한 문장 + 한 애니메이션 스토리 3~5장 → 이모지 질문 → "당신 맞춤" 격려 그래프 → 기상·취침 시간 바로 설정 → 가입이나 결제 벽
- **수면 화면**: 밤 사진·영상 배경(단색 검정 없음), 큰 시계, 실시간 dB, 소리 카드, 밀어서 정지. 시작 전에 권한 이유, 폰 자리 일러스트, 스마트 알람 설명, 오늘 밤 태그를 차례로 보여 줌
- **소리 탭**: ① 큐레이션 사진 카드(길이, New/Free 배지) ② 낱개 아이콘 격자 → 고르면 색으로 채워짐 → 미니 플레이어 → 믹서(소리별 음량, 조합 저장). 재생 화면은 전체 화면 사진 + 원형 타이머
- **리포트**: 원형 점수, 색 단계 막대 + 단계별 시간 4칸, 파형이 있는 소리 클립, 3D 아이콘 통계 타일, 주/월 전환, 기록이 없을 때 흐린 예시
- **콘텐츠**: 기사, 꿈 해몽, FAQ, 퀴즈, 호흡법 7종, 수면 이야기, 명상, 잠들기 전 루틴
- **수익화(따라 하지 말 것)**: 결제 화면 3연속, 가짜 카운트다운, 나갈 때 할인, 룰렛, 광고 다수

## 7. Slipper와 비교한 추천

| 화면 | 지금 Slipper | 추천 |
|---|---|---|
| 처음 실행 | 실제 화면 위 말풍선 튜토리얼 | 애니메이션 소개 4~5장(로고 / 미션을 끝내야 알람이 꺼져요 / 잠들기 전 앱 잠금 / 밤사이 소리·잠 살피기 / 기상 시간 정하기) + 질문 2~3개 → "맞춤 설정" 화면 → 그다음 말풍선 튜토리얼 |
| 수면 탭 | 검정 그라데이션, 다이얼 | 움직이는 밤하늘(별·달, 로티나 영상), 시간대 인사, 일러스트 바로가기(사운드·호흡·몸 풀기·알람), 큰 "수면 시작" |
| 수면 시작 전 | 폰 자리 안내(그림 없음) | 폰 자리 일러스트, 권한 이유 시트, 오늘 밤 태그(카페인·술·운동·늦은 식사·스트레스, 장소 태그는 제외) → 리포트 "이번 주 습관"과 연결 |

| 탐색 | 글자 목록, 최대 2개 섞기 | 사진·영상 카드 2열, 아이콘 타일 격자, 미니 플레이어, 믹서(음량, 조합 저장). 장면 소리 파일(CC0)이 먼저 필요해요 |
| 호흡 | 원 하나, 2종 | 겹친 원·꽃잎 애니메이션, 남은 초 숫자, 진행 막대, 일러스트 카드, 3~4종 |

| 콘텐츠 | 없음 | 우선순위 낮음(짧은 수면 팁 정도). 꿈 해몽은 근거가 약해 비추천 |
| 결제·광고 | 없음 | 경쟁 앱 방식은 따라 하지 않기 |

**주의할 점**
- **의학적 주장 금지**: "무호흡 위험 감지", "뇌파 유도", "두 배 더 깊은 수면", "악몽을 꿨어요" 같은 문구는 쓰지 않아요.
- **유료 라이브러리 규모를 쫓지 않기**: 경쟁 앱의 소리·이야기 수백 개는 대부분 유료예요. Slipper는 CC0 소리 7개 + 소음 3종 + 가이드부터 시작해, 수보다 질을 높여요.
- **스톡 인물 사진**: 쓰려면 상업 라이선스를 확인해야 해요. 일러스트·영상 쪽이 관리하기 쉬워요.
- **분석용 파일**: 이 폴더의 캡처는 앱에 쓰면 안 돼요.
