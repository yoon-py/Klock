# Klock 사운드 라이브러리 설계

작성일: 2026-11-24  
상태: 1차 구현 반영 — 실제 음악 에셋 교체 전

## 1. 결정 사항

이번 버전에서는 알람 화면과 수면 화면을 선택하는 기능을 만들지 않는다.

- 알람 화면은 현재의 기본 Klock 화면 하나를 유지한다.
- 수면 화면은 선택한 사운드와 무관한 단순한 어두운 그라데이션을 사용한다.
- 탐색 탭은 수면 사운드와 알람 사운드를 찾고 미리 듣고 적용하는 라이브러리로 바꾼다.
- 화면 선택 기능은 이미지·영상 에셋과 운영 여력이 준비된 뒤 별도 단계로 검토한다.

## 2. 목표

사용자가 탐색 탭에서 다음 두 종류의 사운드를 선택할 수 있게 한다.

1. 잠들 때 재생할 `수면 사운드`
2. 아침에 울릴 `알람 사운드`

수면 사운드와 알람 사운드는 서로 독립적으로 저장한다. 추가 알람도 각각 다른 알람 사운드와 음량을 가질 수 있다.

## 3. 탐색 탭 구조

탐색 탭 상단에 용도를 고르는 2분할 컨트롤을 둔다.

```text
탐색

[ 수면 사운드 | 알람 사운드 ]

현재 사용 중
┌──────────────────────────┐
│ ▶ 창밖에 내리는 비       │
└──────────────────────────┘

추천
[ 사운드 카드 ] [ 사운드 카드 ] ...

모든 사운드
○ 이름                     ▶
○ 이름                     ▶
```

- 한 탭 안에서 용도를 분리해 잘못 적용하는 일을 줄인다.
- 현재 선택된 사운드는 상단 카드와 목록의 체크 표시로 확인한다.
- 목록의 재생 버튼은 선택을 바꾸지 않고 미리 듣기만 한다.
- 행의 본문이나 체크 영역을 누르면 선택한다.
- 다른 탭이나 화면으로 이동하면 미리 듣기를 중단한다.

## 4. 수면 사운드

### 4.1 콘텐츠 종류

- 자연: 비, 파도, 시냇물, 숲, 풀벌레
- 장소: 모닥불, 밤기차, 선풍기
- 소음: 백색 소음, 분홍 소음, 갈색 소음
- 음악: 잔잔한 피아노, 앰비언트, 로파이, 명상 음악

### 4.2 선택과 믹스

- 기본 선택은 한 개다.
- 자연음·환경음·소음은 최대 두 개까지 섞을 수 있다.
- 음악은 초기 버전에서 다른 음악과 섞지 않는다.
- 음악과 환경음을 섞는 기능은 음량 밸런스와 라이선스 검토 후 후속으로 둔다.
- 각 레이어의 음량은 별도로 조절한다.
- `30분 / 1시간 / 아침까지` 종료 시간을 유지한다.
- 즐겨찾기와 최근 들은 조합을 유지한다.

### 4.3 수면 탭 연결

수면 탭 요약 영역의 `사운드` 행을 `수면 사운드`로 명확히 표시한다.

```text
미션          리듬 맞춰 말하기  >
앱 잠금       오후 8:20부터     >
수면 사운드   비 + 갈색 소음    >
```

행을 누르면 탐색 탭의 수면 사운드 영역으로 이동한다. 수면을 시작하면 선택한 사운드가 재생되고 화면은 중립적인 어두운 배경을 사용한다.

## 5. 알람 사운드

### 5.1 콘텐츠 종류

- 기본 알람: 클래식, 실로폰, 벨, 차임
- 자연 기상음: 새소리, 숲, 시냇물
- 음악형 알람: 피아노, 기타, 밝은 앰비언트, 저작권이 없거나 앱 배포 권리가 확보된 음악

### 5.2 선택 동작

- 한 알람에는 한 개의 사운드를 선택한다.
- 미리 듣기는 10초 뒤 자동으로 멈춘다.
- 같은 재생 버튼을 다시 누르면 즉시 멈춘다.
- 알람 설정 음량으로 미리 듣되 처음부터 너무 크게 재생하지 않는다.
- 알람 실행 시 기존 동작처럼 30초 동안 설정 음량까지 점차 커진다.
- 미션을 시작하면 알람 소리를 완전히 멈춘다.

### 5.3 알람 편집 연결

```text
알람 소리
┌──────────────────────────┐
│ 사운드          새벽 종  > │
│ 🔈 ───────●────── 🔊       │
│ 부드럽게 깨우기       켬   │
└──────────────────────────┘
```

- `사운드` 행을 누르면 탐색 탭의 알람 사운드 영역을 선택 모드로 연다.
- 탐색에서 고른 값은 편집 중인 알람 초안에 반영한다.
- 알람 편집 화면에서 저장해야 실제 알람에 반영한다.
- 기본 수면 일정과 추가 알람은 서로 다른 사운드를 저장할 수 있다.
- 새 추가 알람은 기본 수면 일정의 사운드·음량을 복사한 뒤 독립적으로 변경한다.

## 6. 음악 권리와 라이선스 기준

탐색 탭에는 일반 효과음뿐 아니라 음악도 넣을 수 있다. 단, `라이선스 없음`을 `출처나 사용 권리가 불명확한 음악`이라는 뜻으로 사용하면 안 된다.

앱에 포함할 수 있는 음악:

- 직접 작곡·녹음해 Klock이 권리를 보유한 음악
- 저작권 보호 기간이 끝난 퍼블릭 도메인 음악과 퍼블릭 도메인 음원
- CC0로 배포된 음원
- 상업용 앱에 파일을 내장해 배포할 권리를 명시적으로 구매하거나 허가받은 음원

주의할 음악:

- 클래식 곡의 작곡 저작권이 끝났더라도 특정 연주·녹음에는 별도의 권리가 있을 수 있다.
- `royalty-free`는 저작권이 없다는 뜻이 아니며 앱 내장 배포를 금지하는 상품도 있다.
- CC-BY 음원은 앱 안이나 법적 고지 화면에 요구되는 출처 표기를 제공해야 한다.
- NC, 개인용 한정, 영상 배경음 전용 라이선스는 유료 앱 또는 상업용 앱에 넣지 않는다.
- 스트리밍 서비스나 영상 플랫폼에서 추출한 음악은 넣지 않는다.
- 권리 관계가 확인되지 않은 대중가요와 유명 아티스트 음악은 넣지 않는다.

각 음원은 다음 정보를 에셋과 함께 기록한다.

```ts
type LicenseInfo = {
  kind: 'owned' | 'public-domain' | 'cc0' | 'cc-by' | 'commercial';
  sourceName: string;
  sourceUrl?: string;
  creator?: string;
  attribution?: string;
  proofFile?: string;
  acquiredAt: string;
};
```

출시 빌드에는 권리 정보가 등록되지 않은 음원이 포함되지 않도록 검사한다. CC-BY 음악을 사용하면 설정의 `음원 출처 및 라이선스` 화면에서 표기한다.

## 7. 사운드 카탈로그 모델

현재 `SceneId`가 수면 배경과 소리를 함께 의미하는 구조를 사운드 중심으로 정리한다.

```ts
type SoundId = string;

type SoundAsset = {
  id: SoundId;
  use: 'sleep' | 'alarm' | 'both';
  kind: 'nature' | 'place' | 'noise' | 'music' | 'alarm';
  name: string;
  description?: string;
  source: number;
  previewDurationSec: number;
  loop: boolean;
  mixable: boolean;
  license: LicenseInfo;
};
```

`use`가 `both`인 사운드는 수면과 알람 양쪽 목록에 나타날 수 있지만 선택 값은 각각 따로 저장한다.

## 8. 저장 모델

```ts
SleepSchedule {
  wakeSound: SoundId;
  volume: number;
  haptics: 'default' | 'none';
  gentleWake: boolean;
  // 기존 필드 유지
}

ExtraAlarm {
  wakeSound: SoundId;
  volume: number;
  haptics: 'default' | 'none';
  gentleWake: boolean;
  // 기존 필드 유지
}

SleepSound {
  sounds: SoundId[];
  volumes: { soundA: number; soundB: number };
  offAfter: 30 | 60 | 'morning';
  favorites: SoundId[];
  recent: SoundId[][];
}
```

저장 키는 기존 데이터를 보호하기 위해 당장은 `sleepSound`를 유지한다. 코드의 `scenes` 필드는 마이그레이션 후 `sounds`로 바꾼다.

## 9. 기존 데이터 마이그레이션

- 기존 `sleepSound.scenes`를 같은 ID의 `sounds` 배열로 옮긴다.
- 기존 `volumes.sceneA/sceneB`를 `soundA/soundB`로 옮긴다.
- 추가 알람에 개별 사운드가 없으면 업데이트 시점의 기본 일정 사운드·음량·햅틱을 복사한다.
- 저장된 ID가 새 카탈로그에 없으면 수면은 `brown`, 알람은 `dawn_bell`을 기본값으로 사용한다.
- 기존 즐겨찾기와 최근 조합에서 존재하지 않는 ID만 제거한다.
- 마이그레이션은 한 번만 실행하고 완료 버전을 저장한다.

## 10. 오디오 파일 기준

### 수면 사운드

- 3~10분 길이의 자연스러운 무한 반복
- 갑작스러운 음량 변화, 목소리, 광고, 워터마크 없음
- 화면을 꺼도 재생 가능
- 파일 크기를 줄인 AAC/M4A 사용

### 알람 사운드

- 앱 내부 재생용 전체 버전과 시스템 알람용 30초 이하 버전을 함께 준비
- 시작과 끝이 자연스럽고 반복 재생 시 끊김이 적어야 함
- 파일 자체에 과도한 페이드인을 넣지 않고 앱에서 음량 증가를 제어
- AlarmKit 또는 알림 시스템에 등록할 수 있는 파일 형식 사용

음악이 30초를 넘는 경우 시스템 잠금 화면에서는 짧은 알람 버전이 울리고, 사용자가 Klock을 열면 앱 내부 전체 버전으로 이어지는 구조를 사용한다.

## 11. 중립 테마

초록·청록·시안 색을 앱 전체 배경과 카드에 반복 사용하지 않는다.

- 기본 배경: 검정 또는 매우 어두운 회색
- 카드: 중립 회색
- 본문: 흰색과 회색
- 선택: 흰색 테두리와 체크 표시
- 재생 중 상태: 제한적인 단일 강조색
- 수면 실행 화면과 알람 실행 화면은 기존 단순 배경 하나씩 유지

라이트·다크·시스템 설정은 유지하되 두 모드 모두 중립 팔레트를 사용한다.

## 12. 구현 순서

### 1단계 — 데이터 구조

- 통합 사운드 카탈로그와 라이선스 메타데이터 정의
- 수면 `scenes`를 `sounds`로 마이그레이션
- 추가 알람에 개별 사운드·음량·햅틱 저장

### 2단계 — 탐색 탭

- 수면 사운드·알람 사운드 전환
- 현재 사용 중 카드
- 카테고리와 전체 목록
- 미리 듣기, 선택, 즐겨찾기, 최근 기록

### 3단계 — 설정 연결

- 수면 탭의 사운드 행 연결
- 기본 일정과 추가 알람 편집의 사운드 행 연결
- 선택 모드에서 초안과 실제 설정 구분

### 4단계 — 재생 안정화

- 화면 잠금과 백그라운드 수면 재생 확인
- 알람 미리 듣기와 실제 알람 재생 분리
- AlarmKit용 짧은 파일과 앱 내부 파일 연결
- 미션 진입 시 소리 정지 확인

### 5단계 — 콘텐츠와 테마

- 권리 증빙이 완료된 음악과 효과음 추가
- 라이선스 고지 화면 추가
- 중립 테마로 시각 요소 정리

## 13. 완료 조건

- 탐색 탭에서 수면 사운드와 알람 사운드를 구분해 선택할 수 있다.
- 수면 사운드 두 개를 섞고 각각 음량을 조절할 수 있다.
- 음악형 수면·알람 사운드를 미리 듣고 선택할 수 있다.
- 각 추가 알람이 서로 다른 사운드와 음량을 저장한다.
- 미션을 시작하면 알람 소리가 멈춘다.
- 기존 사용자의 사운드, 즐겨찾기, 최근 조합이 유지된다.
- 권리 메타데이터가 없는 음원은 출시 빌드에 포함되지 않는다.
- 작은 iPhone에서도 재생 버튼과 하단 탭이 겹치지 않는다.
- 라이트·다크·시스템 모드에서 텍스트 대비가 유지된다.

## 14. 후속 범위

- 알람·수면 화면 선택
- 사용자 보유 음원 가져오기
- 음악과 환경음의 고급 믹스
- 온라인 음원 다운로드와 계정 동기화
- 유료 음원 팩과 구독
