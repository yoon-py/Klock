# Slipper MVP 화면 설계 (iOS 26+)

참고: [Alarmy 분석](../ui-research/alarmy.md), [Renight 분석](../ui-research/renight.md)

## 원칙
- 하나의 흐름: 밤 세션 시작 = 내일 알람 예약 + 비트 재생 + 취침 기록.
- 시간대 톤: 밤 = 남색/보라 + 파랑 CTA, 아침 = 주황 톤 + 주황 CTA. 베이스는 다크.
- 탭 3개 (2026-10-10 변경): 알람(해) / 수면(달) / 리포트(문서). 설정은 탭이 아니라 각 화면 우측 상단 톱니 버튼.
  아래 6~8번(오늘-낮, 기록, 설정)은 이 구조로 대체됨. 최신 화면은 시안 캔버스 기준: https://claude.ai/artifact/F3Z9rftu37sTwBmLpRo8EL
- 비주얼: 하늘 그라데이션. 밤(남색, 별, 달, 크림색 CTA) -> 새벽(보라/분홍, 알람과 미션) -> 아침(하늘색, 해, 남색 CTA). 미션은 한 문제마다 하늘이 밝아지고 해가 뜸.
  폰트: 숫자 Outfit 200, 본문 IBM Plex Sans KR, 감성 문구 Gowun Batang.
- 첫 진입 탭: 18:00-03:59 수면, 04:00-17:59 알람. 예외: 알람 울리는 중/미션 미완료 -> 미션, 밤 세션 중 -> 세션, 미션 직후 -> 리포트.
- 역할 분리 (2026-10-10 변경): 알람 탭 = 언제 일어날지, 수면 탭 = 어떻게 잠들지. 기상 시간은 알람 탭에서만 정함.
- 수면 탭: 기상 시간 휠 없음. "지금 자면 N시간 M분" + 내일 아침 알람 카드 + 권장 취침/수면 부채 + 사운드 + 수면 시작.
  알람 카드 탭 -> "내일만 변경" 시트(-15/원래대로/+15/+30분, 휠). 내일 하루만 적용, 반복 알람은 그대로.
  내일 알람이 없으면 카드 자리에 "내일 알람이 없어요 · 알람 추가".

## 전체 흐름

```
[온보딩] 수면 필요량 -> 기본 기상 알람 -> 알람 권한 안내
    |
[오늘(밤)] 기상 시간 확인 -> 수면 시작
    |
[밤 세션] 비트 재생, 알람 카운트다운 -> (재생 끝나면 화면 유지, 소리 페이드아웃)
    |
[시스템 알람(AlarmKit)] [미션 하기] / [중단 -> 1분 뒤 다시 울림]
    |
[구구단 미션] N문제 정답 -> 백업 알람 전부 취소
    |
[기상 완료] 소요시간, 수면시간, 부채 변화, 컨디션 1탭
    |
[오늘(아침/낮)] 어젯밤 요약 + 오늘 밤 권장 취침 시간
```

안전장치: 수면 시작을 안 눌러도 설정의 "기본 기상 알람"(요일 반복)은 항상 예약됨. 수면 시작 시 그날 밤 알람만 덮어씀.

## 화면

### 1. 오늘 - 밤 모드 (구버전: 수면 탭은 위 원칙과 캔버스 기준)
```
┌──────────────────────────────┐
│ 수면 부채 [▮▮▯] 3시간 20분     │
│                              │
│ 내일 몇 시에                   │
│ 일어날까요?                    │
│                              │
│        7 : 10                │
│    ▶   7 : 15   오전          │  <- 휠 피커 (기본값: 기본 기상 알람)
│        7 : 20                │
│                              │
│  지금 자면 7시간 35분           │
│  권장 취침 11:00 PM            │
│                              │
│ ┌──────────────────────────┐ │
│ │ 미션   구구단 4문제        │ │
│ │ 사운드 비트 + 빗소리 45분 > │ │
│ └──────────────────────────┘ │
│ ┌──────────────────────────┐ │
│ │      ▶ 수면 시작하기       │ │  <- 파랑 CTA
│ └──────────────────────────┘ │
│   [오늘]   [기록]   [설정]     │
└──────────────────────────────┘
```

### 2. 밤 세션 (남색 그라데이션, 탭바 숨김)
```
┌──────────────────────────────┐
│                          ⌄   │
│           00:35              │
│   6시간 40분 후에 울려요         │
│                              │
│  ~~~~~~~~~~~~~~~~~~~~~~~~~~  │  <- 느린 파형 (비트 주파수에 맞춰 천천히)
│                              │
│   깊은 휴식으로 가는 중 · 18분 남음 │
│                              │
│  볼륨 ───────●──────          │
│                              │
│      [ 길게 눌러 종료 ]          │  <- 실수 방지
└──────────────────────────────┘
```
- 30초 무조작 시 화면 더 어둡게. 사운드 끝나면 페이드아웃 후 무음 유지.
- 종료 = 세션 취소(알람은 기본 기상 알람으로 되돌림) 확인 시트.

### 3. 알람 (시스템 UI, AlarmKit)
```
 잠금화면 / Dynamic Island
 ┌──────────────────────────┐
 │ Slipper  7:15 기상         │
 │ [ 미션 하기 ]   [ 중단 ]    │
 └──────────────────────────┘
```
- 미션 하기(secondaryIntent) -> 앱 열림 -> 4번.
- 중단(stopIntent) -> 미션 미완료면 1분 뒤 재예약.

### 4. 구구단 미션 (주황 톤, 앱이 알람 소리 계속 재생)
```
┌──────────────────────────────┐
│ ● ● ○ ○              3 / 4   │
│                              │
│       7 × 8 + 3 = ?          │
│                              │
│         [  56  ]             │
│                              │
│   1     2     3              │
│   4     5     6              │
│   7     8     9              │
│   ⌫     0     확인            │
└──────────────────────────────┘
```
- 닫기 버튼 없음. 오답이면 흔들림 + 새 문제, 진행도 유지.
- 앱을 나가면 백업 알람이 1분 뒤 울림.
- 항상 4문제 고정, 난이도 설정 없음. 순서대로:
  1. n + m
  2. n - m (n >= m, 답이 음수 안 나오게)
  3. n × m + k
  4. n × m - k (k <= n × m)
- n, m은 2~9, k는 1~9.


### 8. 설정
- 기본 기상 알람 (시간, 요일, 켜기/끄기)
- 하루 수면 필요량 (기본 8시간)
- 알람 소리
- 사운드 기본값 (배경음 종류, 재생 시간)
- 권한 상태 (알람)

### 9. 온보딩 (3장)
1. 하루에 몇 시간 자야 개운한가요? (6~9시간)
2. 평소 기상 시간과 요일
3. 알람 권한 사전 안내: "미션을 풀어야 꺼져요. 그냥 끄면 1분 뒤 다시 울려요." -> 시스템 권한 팝업

## 수면 분석 (2026-10-10 추가)
- 수면 시작 시 마이크 분석도 시작. Apple SoundAnalysis 기본 분류기(SNClassifierIdentifier.version1)의 snoring, cough, breathing 라벨 사용. 분석은 기기 안에서만.
- 저장: 이벤트(종류, 시작, 길이) + 감지 구간 짧은 클립(7일 보관). 원본 전체 녹음은 저장 안 함.
- 비트 재생 중에는 비트 소리가 마이크에 섞이므로 비트 종료 후부터 분석(또는 그 구간 낮은 신뢰도 처리).
- Apple Watch 사용자는 HealthKit sleepAnalysis(깨어남/렘/코어/깊은)를 읽어 리포트에 표시. 없으면 단계 그래프 숨김.
- 밤새 마이크를 쓰므로 충전 권장 안내. 앱 강제 종료 시 분석은 멈추지만 알람(AlarmKit)은 울림.
- 리포트: 밤 = 어젯밤 단계/소리 타임라인/클립/주간 수면/부채/권장 취침, 아침 = 주간 기상 시각/기상 소요/컨디션 + 밤과 아침 연결 인사이트.

## 계산 규칙 (MVP)
- 수면시간 = 기상 시각(미션 완료) - 수면 시작 시각. 잠들기까지 걸린 시간은 측정 안 함.
- 수면 부채 = 최근 14일 중 기록 있는 날의 sum(필요량 - 수면시간), 0 미만이면 0.
- 권장 취침 = 내일 기상 시각 - 필요량 - 15분 - min(부채/7, 1시간).

## 로컬 데이터 (expo-sqlite)
- settings: need_minutes, default_alarm(time, weekdays), sound_defaults
- sessions: id, started_at, target_wake_at, alarm_fired_at, mission_done_at, condition, sound_params(json)
- sound_events: session_id, kind(snore/cough/noise), started_at, duration_s, clip_path
- sleep_stages: session_id, stage, started_at, ended_at (HealthKit에서 가져옴)
